# Getting help

- **Something broken in the game?** Open a [bug report](https://github.com/nanox333/major-mayhem/issues/new?template=bug_report.yml). If the page crashed, the error screen's *Reset run* button clears only the saved run.
- **Questions, ideas or strategy talk:** use [Discussions](https://github.com/nanox333/major-mayhem/discussions) if they're enabled; otherwise open an issue.
- **A roster, role or photo is wrong:** use the [roster data form](https://github.com/nanox333/major-mayhem/issues/new?template=roster_data.yml).

This is a one-person fan project, so replies can take a few days.
