# NOSCOPE asset provenance

The textured tactical operator was generated for Major Mayhem in Meshy 6 Lite using the project owner's logged-in account, on 2026-10-05. Original file: `Meshy_AI_Full_body_generic_tac_1005150547_texture.glb`. The generation interface displayed CC BY 4.0 for public outputs. Attribution: Major Mayhem / project owner, generated with Meshy 6 Lite. Adaptation: geometry decimation, texture resizing/compression and a procedural reaction skeleton in Blender. No external community Meshy model was downloaded or used.

Environment, sniper silhouette, projectile and environment texture atlas: authored for this project by the Blender/atlas scripts.

The optional source comparison `assets/source/swat.glb` is Quaternius's SWAT, CC0, from https://poly.pizza/m/Btfn3G5Xv4. It is not included in the shipped scene kit.
