# Code of Conduct

Major Mayhem adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming and respectful, argue about ideas rather than people, and remember that the players in this game are real people too. Harassment, personal attacks and discriminatory language aren't accepted in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@nanox333](https://github.com/nanox333), through GitHub (for example with the *Report content* option on the comment, or the private contact listed on the maintainer's profile). Reports are handled confidentially. The maintainer may remove content, or temporarily or permanently ban anyone who breaks this code, as described in the Covenant's enforcement guidelines.
