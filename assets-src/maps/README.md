# Map screenshots

One picture per map, named after the map as the game spells it: `Mirage`, `Inferno`, `Nuke`, `Ancient`, `Anubis`, `Dust2`, `Train` (`.webp`, `.png` or `.jpg`).
`scripts/build-media.mjs` takes the largest file for each map, cuts it to 16:9 and stores it at up to 960x540.

The ones here now are the small (225x125) pictures from bo3.gg's map backgrounds (`https://bo3.gg/img/maps/backgrounds/<map>.webp`). For sharper ones, drop a 1920x1080 screenshot beside
each, for example `Mirage.png`; the larger file is used and the small one is ignored. The Counter-Strike Fandom wiki has 1920x1080 screenshots of every map (for example `Csgo-de-mirage.png`,
`Ancient A Site.jpg`, `Inferno-asite1.png`); its image server blocks scripted downloads, so save them by hand.

These are in-game screenshots: the artwork belongs to Valve, and they are used here only to identify each map in a personal fan project.
