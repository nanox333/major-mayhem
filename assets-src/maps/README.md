# Map screenshots

One picture per map, named after the map as the game spells it: `Mirage`, `Inferno`, `Nuke`, `Ancient`, `Anubis`, `Dust2`, `Train` (`.webp`, `.png` or `.jpg`).
`scripts/build-media.mjs` takes the largest file for each map, cuts it to 16:9 and stores it at up to 960x540.

Six of the seven are 1920x1080 Counter-Strike 2 screenshots (resized to 1280x720 here) from the public GitHub repository `neustcs/cs2mapsthumbnails`: Mirage A site, Inferno A site, Nuke outside,
Ancient A site, Anubis A site and Dust2 Long A. Train is the small (225x125) picture from bo3.gg's map backgrounds (`https://bo3.gg/img/maps/backgrounds/train.webp`), because no CS2 Train picture was found;
drop a larger `Train.png` here and it will be used instead.

These are in-game screenshots: the artwork belongs to Valve, and they are used here only to identify each map in a personal fan project.
